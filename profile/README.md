# InterSim

InterSim — интерактивная платформа для автоматизированной подготовки и симуляции технических интервью.

## О проекте

Платформа предназначена для тренировки и объективной оценки компетенций сотрудников и кандидатов в реалистичном формате собеседования. Система обеспечивает структурированную обратную связь на основе стандартизированных критериев оценки и помогает определить ключевые зоны профессионального роста.

### Основные возможности

- **Реалистичная симуляция**: сценарии технических интервью, адаптированные под специализацию и целевой уровень квалификации (грейд).
- **Объективная оценка**: стандартизированные рубрики и прозрачная шкала оценивания компетенций.
- **Аналитика и обратная связь**: подробные рекомендации по результатам тренировки с выделением сильных сторон и тем для развития.
